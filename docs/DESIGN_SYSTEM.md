# NEXORA — Design System v0.1

## Visual direction
Dark-first technology studio. The visual language comes from the approved NEXORA identity, not from the previous portfolio. The old repository is used only as a source of project names, URLs and thumbnails.

## Brand colors
- Primary Cyan: `#00D1FF`
- Secondary Blue: `#0066FF`
- Dark Navy: `#0B1A3C`
- Light: `#F4F7FB`

## Principles
1. Business clarity before visual spectacle.
2. The hero explains the company before introducing the founders.
3. Cyan/blue are signal colors, not background paint.
4. Depth uses borders, glow and transparency sparingly.
5. Responsive design is structural, not a scaled-down desktop layout.
6. Motion must clarify hierarchy; reduced-motion is respected.
7. Arabic and English share one component system with RTL/LTR switching.

## Theme
Supported modes in the prototype: dark, light and system. User choice is persisted in localStorage under `nexora_theme`.

## Language
Arabic and English are supported in the prototype. User choice is persisted under `nexora_lang`.

## Data notes
Founder data and package content are temporary placeholders. They will be replaced by dashboard-managed content in the backend phase. Project names, URLs and screenshot paths come from the old portfolio repository only.
